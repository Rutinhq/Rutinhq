## RutinHQ

**English** · [Español](#español)

Installable operating systems for small teams, built on AI agents, automations and lightweight web infrastructure.

### Systems

| System | Scope |
| --- | --- |
| [GTM OS](https://www.rutinhq.com/gtm-os) | B2B outbound: ICP filtering, per-account research, personalized first contact, send ledger and weekly results board. |
| [Store OS](https://www.rutinhq.com/store-os) | Shopify: Admin audit and configuration (catalog, variants, pricing, shipping), support macros and FAQ. |
| [NEXUS OS](https://www.rutinhq.com/nexus-os) | Agent-based marketing pipeline: strategy, social and ads. |

Catalog: [docs.rutinhq.com/catalog](https://docs.rutinhq.com/catalog/)

### Engineering practices

- Multi-agent orchestration with defined lanes, human approval gates for deploys, sends and spend.
- Draft PR workflow, CI on every branch, preview before production, documented rollback.
- Secrets only in platform environments; recipient data hashed in reporting.
- Bilingual (ES/EN) sites with SSR, sitemaps, hreflang and security headers.

### Stack

`TypeScript` `React` `Vite` `Next.js` `Cloudflare Workers / Pages / D1` `Vercel` `GitHub Actions` `OAuth 2.0 / OIDC` `Shopify` `Notion API` `Vitest`

### Public code

- [Rutinhq.github.io](https://github.com/Rutinhq/Rutinhq.github.io): source of [www.rutinhq.com](https://www.rutinhq.com).

Client and internal repositories are private.

## Español

[English](#rutinhq) · **Español**

Sistemas operativos instalables para equipos pequeños, construidos sobre agentes de IA, automatizaciones e infraestructura web ligera.

### Sistemas

| Sistema | Alcance |
| --- | --- |
| [GTM OS](https://www.rutinhq.com/gtm-os) | Outbound B2B: filtrado de ICP, investigación por cuenta, primer contacto personalizado, registro de envíos y tablero semanal de resultados. |
| [Store OS](https://www.rutinhq.com/store-os) | Shopify: auditoría y configuración del Admin (catálogo, variantes, precios, envíos), macros de soporte y FAQ. |

### Prácticas de ingeniería

- Orquestación multiagente con carriles definidos y aprobación humana para despliegues, envíos y gasto.
- Flujo de PR en borrador, CI en cada rama, preview antes de producción y rollback documentado.
- Secretos solo en los entornos de cada plataforma; destinatarios con hash en los reportes.
- Sitios bilingües (ES/EN) con SSR, sitemaps, hreflang y cabeceras de seguridad.
